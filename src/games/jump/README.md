# 跳一跳 · 游戏模块

一个可直接在浏览器游玩的单机小游戏，使用 Three.js 绘制场景，cannon-es 处理重力和平台碰撞，不依赖服务端。

## 玩法

- 按住游戏区域、底部“起跳”按钮、鼠标左键或空格键蓄力
- 松开后跳向下一个平台
- 落在平台中心可获得连击加分：2、4、6……
- 跳空后本轮结束，可以重新开始
- 最高分保存在浏览器本地；禁用存储时仍可正常游玩
- `Escape` 或右上角按钮暂停，页面切后台会自动暂停

## 文件

```
game.ts   cannon-es 物理、状态机、落点判定、计分与最高分
scene.ts  Three.js 场景、平台、角色、灯光、镜头与渲染生命周期
```

页面入口：`src/pages/games/JumpPage.vue`。
